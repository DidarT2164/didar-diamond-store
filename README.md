# DIDAR DIAMOND STORE — starter preview

This ZIP contains a responsive, single-page storefront prototype.

## Included
- 8 selectable diamond packages (package 8 is 2200 Diamonds)
- Demo prices in BDT (change these before launch)
- UID and manual payment form UI
- bKash/Nagad selection
- Mobile-friendly layout

## Important before real launch
This is a front-end demo only. It does NOT process payments, verify transaction IDs, look up player names, create real orders, or provide a secure admin panel. Do not accept customer payments with this demo.

To launch a real store, connect:
1. A secure backend and database for orders/admin authentication.
2. A trusted, authorized player UID lookup API through a server-side proxy.
3. A verified payment provider or a secure manual-payment review workflow.
4. HTTPS, privacy/terms pages, refund policy, and support contact.

Open `index.html` in a browser to preview. You can upload the files to a static host for a visual preview, but backend features will remain inactive.
